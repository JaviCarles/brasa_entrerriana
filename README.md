# brasa_entrerriana
Sistema de gestión web para Brasa Entrerriana, desarrollado en ASP.NET bajo arquitectura en capas.

📌 BRASA ENTERRRIANA 🚀 Mi primera aplicación web real desplegada

Después de mucho trabajo puedo compartir Brasa Entrerriana, una plataforma web de gestión y tienda online desarrollada con ASP.NET WebForms y desplegada en servidor externo con dominio personal. Este proyecto comenzó a tomar forma adaptando y evolucionando una estructura base previa, convirtiéndose en una solución funcional y robusta para la comercialización de productos.

🔹 Características principales

Landing page con listado de productos en formato de tarjetas.

Filtros por categoría y ordenamiento por nombre, marca o precio.

Búsqueda dinámica por nombre, marca o categoría.

Botón de WhatsApp para contacto directo y atención personalizada.

Sistema de favoritos para usuarios registrados.

Panel de administración integral para gestionar productos, marcas y categorías.

🔹 Tecnologías utilizadas

ASP.NET WebForms

Bootstrap 5

ADO.NET

SQL Server

C# / .NET Framework 4.8

Manejo de componentes visuales y archivos multimedia

🔹 Aprendizajes clave

Arquitectura sólida en 3 capas (Presentación, Negocio, Datos).

Conexión y gestión remota con SQL Server en entorno de hosting externo.

Diseño responsivo adaptado con Bootstrap y CSS.

Despliegue completo de una aplicación web en un servidor de producción.

Gestión segura de roles de usuario y administración de bases de datos.

👉 Podés ver los sitios funcionando en brasaentrerriana.com y ringoclothes.com.

💡 Este proyecto marca un gran cambio para mi carrera: pasó de ser un código base a convertirse en un sistema real, modular y desplegable, reutilizado con éxito para diferentes marcas y necesidades comerciales.
